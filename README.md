# singularcampers-web

Código y documentación de la web de [Singular Campers](https://singularcampers.com), camperización de furgonetas a medida en Barcelona.

- `wordpress/home/seccion-intro-seo.html` · sección bajo el hero de la home con el H1 «Camperización de furgonetas a medida en Barcelona». Se pega como bloque «HTML personalizado».
- `docs/cambios-seo-2026-11.md` · cambios SEO publicados en noviembre de 2026 y pendientes.
- `docs/prompt-auditoria-seo.md` · prompt para auditar la web con Claude Code / Claude SEO.
- `AGENTS.md` · contexto y reglas para Codex y Claude Code.

Este repositorio no publica nada en la web: los cambios se aplican en WordPress.
